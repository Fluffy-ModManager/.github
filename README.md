# Fluffy Mod Manager

**Fluffy Mod Manager** is a lightweight **RE Engine mod manager for PC games** that makes installing, organizing, enabling, and disabling mods simple.

Instead of manually copying files into game directories, Fluffy Mod Manager gives you an easy way to manage your mod collection from one place. It's designed to be straightforward for beginners while still being useful for players who maintain larger mod setups.

> **Note:** Supported games and available features depend on the version of Fluffy Mod Manager and the game you are using. Check the latest release and documentation for compatibility information.

## 🚀 Getting Started

### Windows

1. Download the latest release from **GitHub Releases**.
2. Extract the downloaded `.zip` file.
3. Open the extracted Fluffy Mod Manager folder.
4. Run `FluffyModManager.exe`.
5. Select your game when prompted.
6. Set the game directory if necessary.
7. Add your mods and activate the ones you want to use.

### Linux

1. Download the latest release.
2. Extract the archive.
3. Open a terminal in the extracted directory.
4. Make the application executable if required:

```bash

```

5. Start the application:


6. Select your game and configure the game directory.

### macOS

1. Download the latest release.
2. Extract the archive.
3. Open Terminal.
4. Navigate to the extracted directory.

## 🔧 Troubleshooting

### The game is not detected

Check that Fluffy Mod Manager is pointing to the correct game installation directory.

If the game was installed through a launcher such as Steam or another storefront, verify the actual installation path.

### A mod does not appear

Make sure the mod is:

* Intended for the game you selected
* Extracted or packaged in the format expected by the manager
* Compatible with your game version
* Placed in the correct mod directory

### The game crashes after enabling a mod

Try disabling recently added mods and launching the game again.

If the game works normally afterward, re-enable your mods one at a time to identify the problematic mod or combination of mods.

### Two mods conflict

Some mods modify the same game files or resources and cannot be used together.

Disable one of the conflicting mods and check the mod author's documentation for compatibility information.
